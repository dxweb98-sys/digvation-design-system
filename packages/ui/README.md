# @digvation/ui

Reusable React component library for Digvation projects. Import the component CSS once in your application entry point:

```tsx
import '@digvation/ui/styles.css';
```

Then use components from the package:

```tsx
import { DButton, DInput, DSelect } from '@digvation/ui';
```

The components use semantic CSS variables so each project can apply its own brand without editing component source code.
